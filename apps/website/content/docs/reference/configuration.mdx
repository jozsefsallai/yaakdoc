Everything is optional. A config file is `yaakdoc.config.json` (`.jsonc`, `.ts` and `.js` work too) in the project directory. See [Project setup](/docs/project-setup#create-a-config-file).

```json title="yaakdoc.config.json"
{
  "$schema": "./node_modules/yaakdoc/config.schema.json",
  "branding": {
    "title": "Acme API"
  }
}
```

The `$schema` gives you autocomplete and validation in your editor. The schema is published with the `yaakdoc` package, and on [unpkg](https://unpkg.com/yaakdoc/config.schema.json).

<Callout>
  The tables on this page are generated from the same schema that validates your config, so they're
  always up to date.
</Callout>
