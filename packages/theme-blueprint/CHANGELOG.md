# @yaakdoc/theme-blueprint

## 0.1.0

### Minor Changes

- 760191d: Add three official themes: Terminal (monospace, with a shell prompt, a file-tree sidebar and a tmux-style status line), Blueprint (a technical drawing, with a title block, a sheet index and requests drawn as schematics) and Editorial (magazine-style, with serif type, numbered figures and side notes). Install one next to your config and use it by its short name, such as `"theme": "terminal"`.
