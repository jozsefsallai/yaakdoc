# @yaakdoc/markdown

Generates Markdown and [llms.txt](https://llmstxt.org) from a [yaakdoc](https://yaakdoc.dev) `PreparedDocument`: `requestToMarkdown`, `folderToMarkdown`, `indexToMarkdown`, `pageToMarkdown`, `llmsTxt` and `llmsFullTxt`.

Secrets are already redacted in the prepared document, so they never appear in the output.

See the [package docs](https://yaakdoc.dev/docs/reference/packages#yaakdocmarkdown) for the functions and their options, and [LLM-friendly output](https://yaakdoc.dev/docs/guides/llms) for what yaakdoc generates.
